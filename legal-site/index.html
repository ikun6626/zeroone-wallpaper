二、我们如何收集和使用个人信息

账号系统收集的信息

为提供账号系统服务，当您主动注册账号时，我们会收集以下账号信息：

  • 用户名：您自定义的昵称或登录名；
  • 密码：仅以不可逆的哈希值形式存储与传输，明文不存储、不传输。

账号注册与登录由您主动触发；不注册账号时，本应用不会收集上述信息。

浏览壁纸：应用会向开发者服务器请求壁纸图片，服务器仅为完成内容分发而处理必要的网络请求，不会据此识别您的身份、不会生成用户画像，也不会记录您的浏览行为。

具体而言，以下类别的信息我们均不收集、不读取、不上传：

信息类别是否收集说明
设备标识符（IMEI / OAID / 序列号等）不收集不读取任何设备标识
位置信息不收集不申请定位权限
相册与照片内容不读取仅在您主动保存时写入，不读取相册内容

麦克风、摄像头不收集不申请相关权限

应用使用行为、崩溃日志不上传本应用不含任何统计或埋点 SDK

三、设备权限说明

本应用申请的权限

1. INTERNET 网络权限：用于从云端获取壁纸内容、每日精选、账号登录与上传用户反馈。壁纸浏览过程中会正常发起网络请求；应用退到后台后不会持续联网。

2. VIBRATE 触感反馈权限：用于收藏、保存、裁剪吸附等操作的轻微振动反馈。属于 HarmonyOS normal 级权限，安装即授予，无需用户单独同意，不涉及任何个人信息收集。

您可在 HarmonyOS 的 设置 → 应用和服务 → 应用管理 → ZeroOne 壁纸 → 权限 中查看与管理上述权限。

关于"保存到相册"功能，需要特别说明：该功能使用的是 HarmonyOS 系统提供的 安全控件（SaveButton）。它由系统直接渲染与鉴权，不属于权限申请：

  • 只有当您主动点击该按钮时，系统才会授予一次性的临时写入授权；
  • 授权仅用于把您当前正在查看的这张图片写入系统相册；
  • 本应用无法读取您相册中的任何已有内容；
  • 临时授权在本次操作完成后即失效，不会在后台持续使用。

四、信息的存储与销毁

本应用数据存储分为两部分：

1. 服务器端（仅当您主动注册账号时）

  • 用户名、密码哈希值保存在开发者自建的服务器（阿里云 ECS，位于中国境内）；
  • 传输全程使用 HTTPS 加密；
  • 密码以不可逆哈希存储，不以明文保存；
  • 壁纸图片本身由开发者服务器存储与分发。

2. 本机沙盒（不离开设备）

  • 收藏记录：壁纸 ID 列表，仅保存在本机、不做云端同步；
  • 图片缓存：为提升浏览流畅度，浏览过的壁纸图片会缓存在本地；
  • 编辑与创作记录：图片编辑、贴纸创作过程中的临时文件与参数。

均保存在应用自身的沙盒目录中，其他应用无法访问。

删除方式：

  • 您可在「我的 → 账号设置」中申请注销账号，我们将在 15 个工作日内删除服务器端账号数据；
  • 卸载本应用即会删除上述全部本地数据（含收藏与图片缓存）；
  • 您也可以在应用内「我的 → 法律与关于 → 清除缓存」中清理图片缓存与导出残留文件（该操作不会删除收藏）。

五、信息的共享、转让与公开披露

除以下情形外，我们不会与任何第三方共享、转让或公开披露您的个人信息：

  • 获得您的明确同意；
  • 根据法律法规规定或行政、司法机关的强制性要求。

我们不会将您的个人信息出境。本应用的服务器位于中国境内。

六、第三方 SDK 与外部链接

本应用未接入任何第三方广告 SDK、统计分析 SDK、消息推送 SDK、崩溃监控 SDK 或社交分享 SDK。

本应用使用 HarmonyOS 官方能力（ArkUI、Image Kit 等）实现界面与图片编辑功能；账号系统、壁纸内容分发、每日精选与用户反馈服务均由开发者自建后端（NestJS + MySQL）提供，不涉及任何第三方云服务。

应用内的外部链接限于：本应用官方法律政策页面（隐私政策、用户协议、关于与版权），用于在浏览器中查看完整文本。应用不会主动跳转至任何其他网页。

七、未成年人保护

本应用不针对未成年人提供专门服务。若您是未成年人，建议在监护人的指导下使用本应用并注册账号。本应用内容为风景、动物、插画等主题壁纸，不含社交、支付、广告或不良信息。

如监护人发现有任何问题，可通过本政策第十一节的方式与我们联系。
