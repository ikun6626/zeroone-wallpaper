二、我们如何收集和使用个人信息

账号系统收集的信息

为提供账号系统服务，当您主动注册账号时，我们会收集以下账号信息：

  • 用户名：您自定义的昵称或登录名；
  • 密码：通过 HTTPS 加密传输；服务端仅保存不可逆哈希值，不保存明文；
  • 昵称（可选）：您可主动设置或修改，用于账号展示。

浏览与未登录收藏无需登录；保存图片与云端收藏同步需要登录账号。账号注册与登录由您主动触发；不注册账号时，本应用不会收集上述账号信息。

浏览与统计：应用会向开发者服务器请求壁纸内容。服务器仅按壁纸维度累计展示/下载次数，用于内容运营统计；不建立与个人身份关联的浏览或下载历史，不生成用户画像，不做个性化推荐。

三、设备权限说明

本应用申请的权限

1. INTERNET 网络权限：用于从云端获取壁纸内容、每日精选、账号登录与上传用户反馈。壁纸浏览过程中会正常发起网络请求；应用退到后台后不会持续联网。

2. VIBRATE 触感反馈权限：用于收藏、保存、裁剪吸附等操作的轻微振动反馈。属于 HarmonyOS normal 级权限，安装即授予，无需用户单独同意，不涉及任何个人信息收集。

您可在 HarmonyOS 的 设置 → 应用和服务 → 应用管理 → ZeroOne 壁纸 → 权限 中查看与管理上述权限。

关于"保存到相册"功能，需要特别说明：该功能使用的是 HarmonyOS 系统提供的 安全控件（SaveButton）。它由系统直接渲染与鉴权，不属于权限申请：

  • 只有当您主动点击该按钮时，系统才会授予一次性的临时写入授权；
  • 授权仅用于把您当前正在查看的这张图片写入系统相册；
  • 本应用无法读取您相册中的任何已有内容；
  • 临时授权在本次操作完成后即失效，不会在后台持续使用。

四、信息的存储与销毁

本应用数据存储分为两部分：

1. 服务器端（注册 / 登录后）

  • 用户名、密码哈希、昵称，以及与账号关联的收藏记录（壁纸 ID、收藏时间）；
  • 保存在开发者自建服务器（阿里云 ECS，位于中国境内），传输全程使用 HTTPS 加密；
  • 密码以不可逆哈希存储，不以明文保存；
  • 壁纸图片本身由开发者服务器存储与分发。

2. 本机沙盒（不离开设备）

  • 登录凭证：access / refresh token，仅保存在本机；
  • 收藏快照：壁纸 ID 列表；登录后与账号云端同步，未登录时仅存本机；
  • 图片缓存：为提升浏览流畅度，浏览过的壁纸图片会缓存在本地；
  • 编辑与创作记录：图片编辑、贴纸创作过程中的临时文件与参数。

均保存在应用自身的沙盒目录中，其他应用无法访问。

删除方式：

  • ①「我的 → 账号设置 → 注销账号」：注销成功后，服务器端账号数据立即删除（最迟不超过 15 个工作日）；
  • ②卸载本应用，删除上述全部本地数据（含登录凭证、收藏快照与图片缓存）；
  • ③「我的 → 法律与关于 → 关于与版权 → 清除缓存」：清理图片缓存与导出残留文件（该操作不影响您的收藏）。

除以下情形外，我们不会与任何第三方共享、转让或公开披露您的个人信息：

  • 获得您的明确同意；
  • 根据法律法规规定或行政、司法机关的强制性要求。

我们不会将您的个人信息出境。本应用的服务器位于中国境内。

六、第三方 SDK 与外部链接

本应用未接入任何第三方广告 SDK、统计分析 SDK、消息推送 SDK、崩溃监控 SDK 或社交分享 SDK。

本应用使用 HarmonyOS 官方能力（ArkUI、Image Kit 等）实现界面与图片编辑功能；账号系统、壁纸内容分发、每日精选与用户反馈服务均由开发者自建后端（NestJS + MySQL）提供，不涉及任何第三方云服务。

应用内的外部链接限于：本应用官方法律政策页面（隐私政策、用户协议、关于与版权），用于在浏览器中查看完整文本。应用不会主动跳转至其他网页；仅在您点击版本更新提示中的「立即更新」时，才会打开后台配置的应用市场或下载页面，该跳转不携带任何个人信息。

七、未成年人保护

本应用不针对未成年人提供专门服务。若您是未成年人，建议在监护人的指导下使用本应用并注册账号。本应用内容为风景、动物、插画等主题壁纸，不含社交、支付、广告或不良信息。

若您未满 14 周岁，请在监护人陪同下阅读本政策，并在取得监护人同意后使用本应用或注册账号。我们不会主动收集未成年人的个人信息；监护人如发现未成年人未经同意注册，可通过第十一节联系我们，我们将在核实后删除相关账号与数据。

如监护人发现有任何问题，可通过本政策第十一节的方式与我们联系。
